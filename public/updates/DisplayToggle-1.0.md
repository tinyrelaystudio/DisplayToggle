# Display Toggle 1.0

The first public release.

## Highlights

- Disable and reconnect MacBook or external displays directly from the menu bar.
- Disabled displays remain available so they can be turned on again.
- Physical display arrivals and removals refresh automatically.
- Audio follows the active display and remembers outputs connected through a display.
- Audio already playing through a remaining active display is left unchanged.
- Start the app automatically when you log in.
- Try every feature free for 14 days without an account or payment card.
- Purchase a $5 license directly from the menu or license window.
- Automatically reconnect disabled displays when trial or license access ends.
- Restore every inactive display from anywhere with Control–Option–Command–R.
- Activate a purchased license on up to three personal Macs.
- Receive signed automatic updates through Sparkle.
- Available in 20 languages.
- Native universal build for Apple Silicon and Intel Macs.

Requires macOS 13 Ventura or later. A purchase includes updates through Display
Toggle 2.x.

## Compatibility note

Disconnecting a display changes the macOS desktop topology. macOS may briefly
blank a remaining display while reapplying its display mode, especially when
the main display is part of a Thunderbolt daisy chain. This is system display
reconfiguration behavior and does not indicate that the cable was disconnected.
