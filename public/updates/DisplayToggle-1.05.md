# Display Toggle 1.05

## Fix

- When the MacBook lid is closed and an external display is connected, the
  built-in display now stays off. Its switch is locked in the menu while this
  applies, and it is turned off again automatically if it comes back on. This
  applies even when the "Built-in off with external" rule is turned off.

Requires macOS 13 Ventura or later. A purchase includes updates through Display
Toggle 2.x.
